# self-test.sh section inventory — the ratchet for #891.
#
# One line per `# ─── <title> ───` header in agent/self-test.sh, normalized to
# the title text alone. §1k compares this list against the file and FAILS on any
# entry that is present here and absent there.
#
# It exists because sections have twice vanished without anyone deciding to
# remove them: #889 (a `git merge main` resolved an overlapping hunk in favour
# of the branch and deleted §9i, the #877 guard) and #892 (a new check was
# written over §1i, deleting the weekly-analytics shape-parity comparison
# outright). Both were caught by a human reading a diff. Neither was caught by
# anything that runs.
#
# Titles, not just section letters, and that is deliberate: #892 kept the letter
# §1i and replaced what was under it. An inventory of letters would have called
# that file complete.
#
# Sections may be added and they may be REMOVED — this is not a freeze. It only
# requires that a removal be a line deleted from this file, in the same commit,
# visible in the same diff. Adding a section without recording it here is a WARN
# naming the line to add, never a FAIL: an open PR must not be able to turn main
# red by merging first.
#
# Lines starting with `#` and blank lines are ignored.
